# 认知康复一体化系统演示模式

演示模式用于项目汇报、导师展示和比赛路演。它允许在没有真实后端、没有真实 EEG 设备的情况下展示统一登录入口、角色工作区、训练流程、模拟 EEG、治疗师报告和机构管理入口。

## 数据边界

- 所有演示账号、训练记录、EEG 数据、风险提醒、音乐推荐、处方和报告均标记为“演示数据 - 非真实训练记录”。
- 演示数据只用于展示辅助训练、状态观察、训练记录和趋势分析能力。
- 演示文案不得表达确诊、治愈、疗效保证或真实训练效果判断。
- 演示模式不绕过正式权限系统；真实后端接入后应由 API 返回授权范围。

## 演示账号

| 身份        | 演示账号         | 演示口令    | 展示空间                                 |
| ----------- | ---------------- | ----------- | ---------------------------------------- |
| 训练用户    | `demo-trainee`   | `demo-pass` | 认知训练舱、模拟 EEG、音乐疗愈、训练流程 |
| 家长/监护人 | `demo-parent`    | `demo-pass` | 阶段简报、训练坚持情况、下次建议         |
| 治疗师      | `demo-therapist` | `demo-pass` | 康复数据指挥中心、用户详情、报告中心     |
| 机构管理员  | `demo-admin`     | `demo-pass` | 机构概览、权限边界、设备和操作日志入口   |

## 推荐演示流程

1. 打开统一登录页。
2. 点击“演示模式”里的治疗师演示账号。
3. 查看康复数据指挥中心，说明今日概览、训练趋势、风险提醒和待处理任务均为演示数据。
4. 进入某个用户详情，查看注意力、反应时、误按率、漏按率和 EEG 趋势。
5. 打开报告中心，展示 mock 周报与训练摘要。
6. 退出或回到统一入口，点击训练用户演示账号。
7. 进入认知训练舱，查看今日任务、推荐音乐、训练进度和 EEG 状态。
8. 进入音乐疗愈或训练流程，展示模拟 EEG 与训练安全提示。
9. 返回治疗师端，展示报告中心和提醒列表的演示数据标识。

## 技术入口

- 演示配置：`packages/ui-components/src/demo-mode.ts`
- 演示认证：`mockAuth` / `mockDemoAuth`
- 模拟 EEG：`mockEEGStream` / `createMockEEGStream`
- 演示训练数据：`mockTrainingData`
- 统一登录入口：`UnifiedAuthPortal`

## 关闭或替换演示模式

`UnifiedAuthPortal` 支持传入 `demoModeConfig={false}` 隐藏演示入口。正式环境可以保留真实登录表单，同时将 `authClient` 替换为后端认证 API。

真实后端接入时建议保留 `demo` provider 类型，仅用于本地、汇报或沙盒环境；生产环境应由环境变量或构建配置关闭演示入口。
